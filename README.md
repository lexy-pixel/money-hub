# Home Money Hub

Home Money Hub is a static iPhone web app for household money: bills and paycheck set-asides, a due-date calendar, coupon and deal notes, home stock, a tax deduction log, and college costs.

All data stays on the phone in browser storage. Nothing is uploaded.

Open it at https://lexy-pixel.github.io/money-hub/

## Install on iPhone

1. Open the link in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
